# Bumi 🌴

A Shikaku puzzle game (Portuguese, azulejo-themed) — divide the grid into rectangles matching the numbered clues.

Expo Router app targeting iOS, Android, and web. Originally rewritten from a single-file HTML prototype (still available at [jarvismaia97/shikaku](https://github.com/jarvismaia97/shikaku)).

### Setup

```bash
npm install
npm run web      # or: npm run ios / npm run android
npm test         # unit tests for src/game/*
```
